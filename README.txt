==================================================
 Buhly v1.0 • ГосПорталы Республики Беларусь
==================================================

Умный пульт управления для входа на государственные порталы:
 * МНС (Налоговая) — lkfl.portal.nalog.gov.by
 * Фонд (ФСЗН 2.0) — portal2.ssf.gov.by
 * ЭСЧФ (НДС) — vat.gov.by (в 1 клик через режим IE)

ПРЕИМУЩЕСТВА:
 1. Работает без установки (портативная версия, весит меньше 1 МБ).
 2. 100% безопасность: программа работает только локально на вашем ПК,
 не собирает пароли, не перехватывает ключи и не передает данные.
 3. Использует ваши родные браузеры (Microsoft Edge и Google Chrome).
 4. Автоматически проверяет статус доступности серверов и портов.

КАК ЗАПУСТИТЬ:
 * Просто запустите файл Buhly.exe.
 * Или дважды кликните по файлу Создать ярлык на Рабочем столе.cmd.
