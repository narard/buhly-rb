Три главные причины, почему ломается вход в МНС

Даже если вчера Личный кабинет МНС работал идеально, сегодня вход может сломаться по одной из трех причин: старые прокси-утилиты прописали адрес 127.0.0.1 account.gov.by в системный файл hosts (из-за чего браузер стучится на выключенный локальный порт и получает ERR_CONNECTION_REFUSED), открытая программа EDeclaration перехватила USB-токен, либо отвалился порт 8084 / AvTunProxy.

Также в браузере может не открываться страница выбора сертификата на e-pasluga.by и едином портале авторизации account.gov.by, если сбился туннель.

Как исправить вручную в Windows 10/11

  1. Откройте Блокнот от имени администратора и проверьте файл C:\Windows\System32\drivers\etc\hosts. Удалите строки с 127.0.0.1 для account.gov.by, nalog.gov.by, vat.gov.by, ssf.gov.by и e-pasluga.by.
  2. Выполните в командной строке ipconfig /flushdns для сброса DNS-кеша Windows.
  3. Полностью закройте АРМ «Плательщик» (EDeclaration) и менеджер MngCert, затем проверьте работу AvTunProxy и порта 8084.

Частые вопросы

Почему именно account.gov.by выдает ERR_CONNECTION_REFUSED?

Некоторые старые программы для криптографии перехватывают трафик через системный файл hosts (127.0.0.1 account.gov.by). Когда старая программа не запущена, браузер пытается подключиться к вашему же компьютеру вместо реального сервера.

Подходит ли Buhly одновременно для МНС и для Е-Паслуги (e-pasluga.by)?

Да, в Buhly v3.1 есть отдельные кнопки для Личного кабинета МНС, ФСЗН 2.0, ЭСЧФ (vat.gov.by) и Е-Паслуги (e-pasluga.by).

Видит ли программа мой пин-код от флешки налоговой?

Нет. Ввод пин-кода происходит только в стандартном системном окне Авест/ГосСУОК при входе на сайт министерства.
