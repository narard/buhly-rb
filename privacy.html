Политика приватности и защиты данных (buhly.by)

Политика в отношении обработки персональных данных при использовании веб-сайта buhly.by и локальной десктопной программы Buhly в соответствии со статьями 9 и 17 Закона Республики Беларусь от 7 мая 2021 г. № 99-З «О защите персональных данных».

1. Сведения об операторе / владельце проекта

Владелец сайта buhly.by и автор открытого некоммерческого проекта Buhly (лицензия MIT) — физическое лицо (Республика Беларусь), разработчик открытого ПО.

  • • Контакты для обращений по вопросам защиты персональных данных: GitHub @narard, Telegram @max_repin (или чат поддержки @buhly_by_chat), электронная почта: support@buhly.by.
  • • Цель политики: обеспечить прозрачность работы локальной программы и сайта без скрытого сбора данных, профилирования и навязанных подписок.

2. Десктопная программа Buhly (.exe) — локальное хранение и сеть

Программа Buhly Desktop (Buhly.exe) обрабатывает ваши коммерческие и учётные файлы исключительно локально на вашем персональном компьютере. Владелец проекта не собирает, не хранит и не имеет доступа к вашим отчётам, выпискам и реквизитам.

  • ✓ Никакой отправки учётных данных: ваши отчёты Wildberries и Ozon, банковские выписки, накладные ТН-2 и 11-графная ТТН-1 (из поставок WB и Ozon), расчёты налогов (кассовый метод УСН 6%, вычет ИП 30%/20%, ввозной НДС), справочники себестоимости, профили организаций (УНП, расчётные счета) и реестр сроков ЭЦП не передаются на серверы разработчика или третьим лицам.
  • ✓ Точный перечень локальных путей хранения на ПК пользователя:
    • — %LOCALAPPDATA%\Buhly\ (профили компаний profiles.xml, реестр ЭЦП cert_registry.tsv, справочник себестоимости, кеш ежедневной проверки версии update_check.txt);
    • — %TEMP%\Buhly_error.log (локальный журнал ошибок запуска/работы) и временные демо-файлы в %TEMP%\Buhly_Demo\;
    • — Documents\Buhly_* (папки Документы\Buhly_ТН и Документы\Buhly_Аналитика для сформированных накладных и таблиц КУДиР/1С);
    • — Desktop\Buhly_Diag_*.txt (обезличенный файл диагностики структуры отчёта/выписки без сумм и ФИО/УНП — создаётся только при нажатии пользователем кнопки «Диагностика файла», резервный путь %TEMP%\Buhly_Diag_*.txt).
  • ✓ Нет доступа к закрытым ключам ЭЦП: программа не запрашивает PIN-код от USB-токена Авест и не извлекает закрытые ключи.
  • ✓ Сетевые обращения программы и режим «Полный офлайн»: по инициативе пользователя выполняются запросы к официальным сервисам РБ (nbrb.by — курсы валют, portal.nalog.gov.by — проверка УНП по ГРП МНС, проверка доступности 4 госпорталов: nalog.gov.by, portal2.ssf.gov.by, vat.gov.by, e-pasluga.by) со строгой проверкой TLS 1.2. Кроме того, 1 раз в календарные сутки при запуске программа выполняет анонимную проверку новой версии на https://api.buhly.by/api/version (с резервными узлами buhly-stats.repinm911.workers.dev, buhly.by/version.json и api.github.com) — без передачи ПДн, файлов или идентификаторов ПК (на сервере увеличивается только общий обезличенный суточный счётчик без сохранения IP-адресов). В настройках Buhly v3.2 предусмотрен тумблер отключения проверки обновлений («Полный офлайн»), полностью выключающий фоновые проверки версии.

3. Сайт buhly.by, удаление сторонних CDN и трансграничный доступ

Сайт buhly.by является открытым информационным ресурсом без регистрации, форм ввода ПДн и рекламного трекинга:

  • ✓ Полное удаление сторонних CDN: внешние CDN-библиотеки и сторонние шрифты (Tailwind CDN, Google Fonts) с сайта полностью удалены. Таблица стилей (styles.css) и иконка (favicon.ico) загружаются локально с того же домена.
  • ✓ Без cookie-файлов и профилирования: на сайте не устанавливаются отслеживающие cookie, не используется localStorage для идентификации посетителей и не ведутся профили поведения.
  • ✓ Обезличенная статистика и клики скачивания: для подсчёта посещаемости и скачиваний применяются cookie-free сервис Cloudflare Web Analytics и неблокирующий ping-запрос при клике скачивания на https://api.buhly.by/api/download/*?ping=1 (резервно buhly-stats.repinm911.workers.dev), а также передача UTM-меток в ссылках текущей сессии без сохранения ПДн.
  • ✓ Трансграничная передача / доступ (ст. 9 Закона № 99-З): поскольку сайт размещён на инфраструктуре GitHub Pages (GitHub, Inc., США), дистрибутивы загружаются с GitHub Releases, а аналитика и проверка обновлений обслуживаются через сеть Cloudflare (Cloudflare, Inc., США/ЕС), при открытии сайта или скачивании релиза технические сетевые данные (HTTP-заголовки, IP-адрес на уровне транспортного соединения хостинга/CDN) обрабатываются за пределами Республики Беларусь в соответствии с политиками GitHub и Cloudflare. При добровольном переходе по ссылкам в Telegram (t.me/buhly_by, t.me/buhly_by_chat) действуют правила Telegram.

4. Сроки хранения и права субъекта персональных данных

  • • Сроки хранения: все локальные файлы программы (%LOCALAPPDATA%\Buhly, %TEMP%\Buhly_error.log, Documents\Buhly_*, Desktop\Buhly_Diag_*.txt) хранятся исключительно на устройстве пользователя и могут быть удалены им в любой момент. Агрегированные суточные счётчики Cloudflare Worker (без IP и идентификаторов устройств) имеют автоматический срок хранения 90 дней (TTL KV), суммарные обезличенные счётчики и агрегированная статистика Cloudflare Web Analytics хранятся в обезличенном виде без привязки к субъектам ПДн.
  • • Ваши права по Закону РБ № 99-З (ст. 10–14, ст. 17): вы вправе отозвать согласие (если обработка осуществляется на его основании), получить информацию об обработке своих персональных данных, требовать их изменения, прекращения обработки или удаления, получать сведения о предоставлении ПДн третьим лицам, а также обжаловать действия/бездействие оператора в уполномоченный орган по защите прав субъектов персональных данных — Национальный центр защиты персональных данных Республики Беларусь (НЦЗПД).
  • • Порядок реализации прав: направьте обращение владельцу проекта по контактам из раздела 1 (support@buhly.by, @narard, @max_repin или @buhly_by_chat). Поскольку программа работает локально и не передаёт ваши ПДн разработчику, удаление учётных данных на ПК выполняется вами самостоятельно удалением соответствующих папок.

5. Проверка открытого кода и обратная связь

Исходный код Buhly полностью открыт по лицензии MIT — любой специалист по информационной безопасности может проверить отсутствие скрытой телеметрии и собрать Buhly.exe самостоятельно штатным компилятором Windows (build.bat).
