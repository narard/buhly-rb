Политика приватности и защиты данных (buhly.by)

Подробное описание принципов приватности десктопной программы Buhly и веб-сайта buhly.by в соответствии с Законом Республики Беларусь от 7 мая 2021 г. № 99-З «О защите персональных данных».

1. Десктопная программа Buhly (.exe) — 100% локально

Программа Buhly Desktop (Buhly.exe) работает исключительно на вашем персональном компьютере с политикой 0% телеметрии. Разработчики не имеют доступа к вашим коммерческим и персональным данным.

  • ✓ Никакой отправки учётных данных: ваши отчёты Wildberries и Ozon, банковские выписки, накладные ТН-2/ТТН-1, справочники себестоимости, профили организаций (УНП, расчётные счета) и реестр сроков ЭЦП никогда не передаются на серверы разработчика или третьим лицам.
  • ✓ Локальное хранение: настройки и рабочие реестры сохраняются только в вашей пользовательской папке Windows (%LOCALAPPDATA%\Buhly).
  • ✓ Нет доступа к закрытым ключам ЭЦП: программа не запрашивает PIN-код от USB-токена Авест и не извлекает закрытые ключи.
  • ✓ Прямые запросы только к госсервисам РБ и проверка обновлений: рабочие запросы выполняются только по вашей инициативе и строго напрямую к официальным доменам Республики Беларусь (nbrb.by для курсов валют, portal.nalog.gov.by для проверки УНП по ГРП МНС и официальные госпорталы) со строгой проверкой TLS 1.2. Кроме того, 1 раз за календарные сутки при запуске программа может проверять наличие новой версии на buhly-stats.repinm911.workers.dev/api/version (или GitHub Releases): на сервере учитывается только общий обезличенный счётчик проверок за день без сохранения IP-адресов, идентификаторов ПК или каких-либо данных пользователя.

2. Сайт buhly.by — аналитика без cookie и профилирования

Сайт buhly.by является информационным ресурсом с открытым исходным кодом и спроектирован так, чтобы минимизировать сбор любых сведений о посетителях:

  • ✓ Без cookie-файлов и скрытого трекинга: на сайте не устанавливаются рекламные или отслеживающие cookie, не используется localStorage для идентификаторов пользователей, не ведётся поведенческое профилирование и не подключаются системы записи экрана вроде Вебвизора.
  • ✓ Обезличенная cookie-free статистика: для оценки востребованности инструкций и релизов может применяться только агрегированная cookie-free веб-аналитика (например, Cloudflare Web Analytics) и передача обезличенных UTM-меток в пределах текущей сессии без сохранения персональных идентификаторов.
  • ✓ Добровольные внешние переходы: ссылки на скачивание релиза с GitHub (github.com/narard/buhly-rb), а также на канал и чат в Telegram (t.me/buhly_by, t.me/buhly_by_chat) являются необязательными. При переходе на эти внешние площадки действуют политики конфиденциальности соответствующих сервисов (GitHub / Telegram).

3. Проверка открытого кода и обратная связь

Исходный код Buhly полностью открыт по лицензии MIT — любой специалист по информационной безопасности может проверить отсутствие скрытой телеметрии и собрать Buhly.exe самостоятельно штатным компилятором Windows (build.bat).
